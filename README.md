# NUVORA

AI-powered marketplace / discovery platform.

## Status

Frontend foundation + Core UI System.

## Technology

- React
- Vite
- Tailwind CSS
- React Router
- Sora (display typeface)
- Manrope (interface / body typeface)
- Material Symbols (icons)

## Getting started

```bash
cd frontend
npm install
npm run dev
```

The original Stitch HTML prototypes (`*.html`) are kept as the visual source of truth and are not part of the React build.
